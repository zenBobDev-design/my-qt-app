## 📖 项目简介
这是我的第一个 C++ / Qt 桌面应用程序练习项目。
主要目的是熟悉 Qt Creator 开发环境、信号与槽机制以及 C++ 基础语法。

## 🛠️ 技术栈
- **语言**: C++
- **框架**: Qt 6 (Widgets)
- **构建工具**: qmake
- **IDE**: Qt Creator

## 🚀 如何运行
1. 确保已安装 Qt 6 开发环境。
2. 使用 Qt Creator 打开 `MyFirstApp.pro` 文件。
3. 点击左下角的"运行"按钮（绿色三角形）即可编译运行。
